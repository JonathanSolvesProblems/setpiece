# Gallery captions

One block per image, in gallery order. Paste the block, nothing else.

## 01 say

```
"A night chase, a red car past a burning truck, two actors running at camera, a dragon on a rooftop", built piece by piece.
```

## 02 table

```
"Workers building an aircraft, a ladder up to its roof", said once. A 1:10 set on the real table, its own sky behind it, your hands on it.
```

## 03 made

```
Asked for a castle gate, it built the gate and two towers from simple wooden shapes, then two guards and a horse, low and wide.
```

## 04 look

```
Once the set is up it is shown its own camera's picture and how much of the frame each piece takes. It moves the camera if the shot is off.
```

## 05 light

```
The light comes from the sentence: a night chase is night, a duel at sunset golden hour. After dark the windows and the lamp are lit.
```

## 06 draw

```
One frame four ways: as the lens sees it, a pencil storyboard, anime (the set itself turns cartoon), and hard black and white.
```

## 07 coverage

```
Shot 4 of 6, in the headset: the designer planned the coverage, the camera goes to each shot and the board fills by itself. Six in 25 s.
```

## 08 pinch

```
A hand carries the dragon off the roof onto the truck. Pinch a piece or close a fist on it; let go in the air and a dragon stays there.
```

## 09 speed

```
On the headset: the first piece 1.6 s after my last word, the set whole inside 4 s, six shots on the storyboard 25 s after Cover it.
```

## 10 leave

```
Saved from the page: the board the designer shot, each frame with its lens and height, and the shot list as a CSV for the crew.
```
