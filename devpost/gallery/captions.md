# Gallery captions

One block per image, in gallery order. Paste the block, nothing else.

## 01 table

```
A 1:10 film set lands on your real table. Two wooden stand-ins, a tennis ball for the creature, a 35 mm camera, your own hands.
```

## 02 pinch

```
Put your fingers on a piece and pinch, or close a fist around it. The pointing ray steps aside when a hand is near a piece.
```

## 03 say

```
"A Mexican standoff after a car chase": three actors on marks, each aiming at the next, two crashed cars behind. All of it movable.
```

## 04 heard

```
The recogniser runs inside the page, so nothing you say leaves the headset. 14 of 14 standoff lines from two synthetic voices came through.
```

## 05 board

```
Each frame on the board is stamped with its lens, camera height, distance and every actor’s eyeline, measured where the pieces stood.
```

## 06 lenses

```
The same blocking through an 18 mm and a 50 mm. The monitor above the set shows what the lens sees before you snap.
```

## 07 take

```
Carry an actor across while it records and they walk it back, in step, on the floor. Up to twelve seconds, kept with the board.
```

## 08 fire

```
Rain over a fire puts it out. A car driven into an actor knocks them down. A take replays what the blocking does, not what you wish it did.
```

## 09 library

```
Cast, creatures, vehicles, effects, set and props, every one a bare maquette you can paint, size and fit out. 10 scenes to start from.
```

## 10 scene

```
Dragon attack: a dragon, a house on fire and two actors, placed as a blocking. Start here, then move anything.
```

## 11 back

```
Put the headset on again and the set is on the same spot of the same table, with the board you left. The panel says so.
```

## 12 fps

```
59 one-second samples over two sessions of normal use on a Quest 3S: median 90.0, lowest 65.5 in the first minute, 0 under 60.
```

## 13 load

```
While the set builds, the card names each step. The app is 2.54 MB, down from 6.78; a reload on the Quest is ready in 3.4 s.
```

## 14 leave

```
Back in the browser: the board as an image, the shot list as a CSV and the take as a short animatic, saved to your own files.
```

## 15 camera

```
Four sensor formats, a tripod or a drone up to 11 m on the real set, and a second camera you can cut to while a take records.
```

node tools/check-live.mjs asserts 35 things about the live site, no account and no key. Last run: 35 of 35 passed.
