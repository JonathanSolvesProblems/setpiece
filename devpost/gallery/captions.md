# Gallery captions

One block per image, in gallery order. Paste the block, nothing else.

## 01 castle

```

```

## 02 say

```
"A night chase, a red car past a burning truck, two actors running at camera, a dragon on a rooftop", built piece by piece.
```

## 03 evolve

```
Said in the headset, one after another. Each change lands in seconds and leaves the rest of the set as it was.
```

## 04 look

```
Once the set is up it is shown its own camera's picture and how much of the frame each piece takes. It moves the camera if the shot is off.
```

## 05 rider


## 06 inside

```

```
