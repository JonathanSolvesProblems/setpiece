# Gallery captions

One block per image, in gallery order. Paste the block, nothing else.

## 01 say

```
"A night chase, a red car past a burning truck, two actors running at camera, a dragon on a rooftop", built piece by piece.
```

## 02 table

```
A 1:10 film set lands on your real table. Two wooden stand-ins, a tennis ball for the creature, a 35 mm camera, your own hands.
```

## 03 made

```
Asked for a castle gate, it built the gate and two towers from simple wooden shapes, then two guards and a horse, low and wide.
```

## 04 look

```
It is shown the camera's picture and what each piece covers. A truck in the way, a dragon cut off: it moves the camera and looks again.
```

## 05 dresser

```
The designer's own plan stood two actors inside a car parked side-on. Code stepped them out beside it before the camera was placed.
```

## 06 speed

```
7 fresh sets from a desktop: the first piece a median 1.8 s after asking, the whole set 3.0 s. Headset time is next.
```

## 07 pinch

```
Put your fingers on a piece and pinch, or close a fist around it. The pointing ray steps aside when a hand is near a piece.
```

## 08 board

```
Each frame on the board is stamped with its lens, camera height, distance and every actor’s eyeline, measured where the pieces stood.
```

## 09 lenses

```
The same blocking through an 18 mm and a 50 mm. The monitor above the set shows what the lens sees before you snap.
```

## 10 take

```
Carry an actor across while it records and they walk it back, in step, on the floor. Up to twelve seconds, kept with the board.
```

## 11 fire

```
Rain over the fire puts it out. A car pushed hard and let go drives on, and the actor in its way goes down.
```

## 12 library

```
Cast, creatures, vehicles, effects, set and props, every one a bare maquette you can paint, size and fit out. 10 scenes to start from.
```

## 13 back

```
After a reload in the headset the panel lists what came back: the set, the pieces and the board. Same spot after a relaunch: next to prove.
```

## 14 fps

```
48 one-second samples, 5, 6 and 12 Nov: median 89.9, lowest 65.5. A heavier set on 11 Nov ran at 66 to 68, 73 to 82 after the fix.
```

## 15 leave

```
Saved from the page: the board as an image with each frame’s numbers, and the shot list as a CSV. A take saves as a short video too.
```

## 16 camera

```
Four sensor formats, a tripod or a drone up to 11 m on the real set, and a second camera you can cut to while a take records.
```
